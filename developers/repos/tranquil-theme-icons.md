# tranquil-theme-icons

File-type icons and colors for the tree-view. Colors are semantic (what a file does, not its
language): blue code, yellow config, teal data, pink graphics, orange `.url`, gray
infrastructure. Each UI theme gets its own `.icon-colors()` block, so a new theme needs one. Read
[rules/ui-themes.md](../rules/ui-themes.md).
